# Phased build prompts

## Phase 1 — prove behavior

Observe five affected borrowers using the current prototype without coaching. Add event names for started/completed brief, method disclosure, official-source click, and saved checklist—never financial values. Produce a findings memo with direct user language and a go/kill decision for the $29 concierge brief.

## Phase 2 — versioned policy contract

Replace duplicated formulas with a language-neutral, effective-dated policy schema and golden test vectors consumed by TypeScript and Python. Require citations, owner, review date, expiry, and kill-switch state. Return policy metadata with every calculation and add stale/unavailable error UX.

## Phase 3 — notice-to-call concierge

Add encrypted notice upload, malware scanning, bounded PDF extraction, schema validation, user confirmation, review queue, printable brief, consent, retention, and deletion. AI may draft extracted fields and questions but cannot select a repayment plan or modify deterministic math. Add redacted observability and authorization tests.

## Phase 4 — counselor pilot

Build tenant-scoped case collaboration for one nonprofit counseling partner. Add append-only case events, reviewer roles, SLA dashboards, escalations, and export. Run a 100-borrower pilot measuring comprehension, checklist use, resolution time, paid conversion, and adverse outcomes before broader launch.
